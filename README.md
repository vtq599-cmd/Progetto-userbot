# Progetto Userbot (Termux)

Telegram userbot на Telethon с обязательным MTProxy. Команды начинаются с `7`; старое значение `BOT_PREFIX=.` автоматически заменяется на `7`.

## Установка

1. В Termux клонируй репозиторий и запусти `bash termux-install.sh`.
2. Заполни `userbot/.env`: `API_ID`, `API_HASH`, `PROXY_SERVER`, `PROXY_PORT` и `PROXY_SECRET`.
3. Запусти `bash termux-run.sh`. По умолчанию бот предложит вход через QR.

`POLLINATIONS_API_KEY` в `userbot/.env` нужен для `7ai` и `7sr`. Ключ создаётся на [странице Pollinations API keys](https://enter.pollinations.ai/keys). Не публикуй его и не отправляй в чат.

Для `7vtt` можно отдельно указать `WIT_TOKEN`. Без него распознавание речи отключено, сам бот продолжит запускаться.

## Команды

- Базовые: `7alive`, `7ping`, `7purge`, `7purgeme`, `7pin`, `7unpin`, `7unpinall`, `7afk`, `7unafk`, `7tagall`, `7q`, `7cut`, `7vnote`, `7chatlink`.
- Модерация: `7kick`, `7ban`, `7unban`, `7mute [минуты]`, `7unmute`, `7warn`, `7unwarned`.
- Дополнительно: `7onl on|off`, `7yt ссылка`, `7tt ссылка`, `7ai вопрос`, `7ai image описание`, `7ghost on|off`, `7vtt` (ответом на аудио), `7snote текст`, `7first`, `7sr on|off`, `7time [город или timezone]`, `7tts [голос] текст`, `7save` (ответом на медиа), `7stats [дни]`, `7whodeleted on|off`, `7id`, `7ui`, `7chatinfo`, `7ls`, `7link`, `7tr [язык] текст`, `7weather город`, `7restore [количество]`, `7editmess` (ответом на сообщение).
- `7d` удаляет только саму команду.

Все обработчики команд проверяют начало сообщения: текст вроде `напиши 7ping` командой не считается.

## Ограничения истории Telegram

- Восстановление и `7first` используют локальный кэш сообщений, который заполняется после запуска новой версии. Для удаления доступен сохранённый текст; удалённые медиа не восстанавливаются, если файл заранее не был сохранён.
- Telegram не возвращает сообщения, удалённые до запуска кэша, и не во всех чатах сообщает инициатора удаления. `7whodeleted` дополнительно проверяет журнал действий администраторов там, где Telegram разрешает это аккаунту.
- `7editmess` показывает правки, увиденные после запуска этой версии; старые версии Telegram не предоставляет.
- `7snote` удаляет сообщение по событию прочтения, когда Telegram передаёт отметку прочтения; через пять минут действует резервное удаление.
